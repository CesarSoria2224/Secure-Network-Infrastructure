# Notas técnicas de diseño

Espacio para explicar las decisiones técnicas del proyecto usando el informe original como fuente.

## Secciones sugeridas

1. Requerimientos y objetivos.
2. Segmentación de red y plan de direccionamiento.
3. Seguridad perimetral: pfSense, firewall, IDS/IPS, VPN y DMZ.
4. Virtualización, servicios y respaldos.
5. Alcance, limitaciones y posibles mejoras.

**Importante:** diferenciar claramente lo **propuesto** de cualquier configuración o prueba que se haya realizado realmente.
