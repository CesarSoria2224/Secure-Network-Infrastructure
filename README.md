# Secure Network Infrastructure — Alcaldía Municipal

**Proyecto académico de diseño de infraestructura de red segura**  
**Autor:** Cesar Soria Mita

**Materia:** Seguridad en Redes II | **Fecha del informe:** 13 de junio de 2026

## Descripción

Propuesta de diseño y planificación de una infraestructura de red para una alcaldía municipal de aproximadamente 80 usuarios, con posibilidades de crecimiento. El proyecto aborda la segmentación de red, la seguridad perimetral, el acceso remoto seguro, los servicios de infraestructura y la continuidad operativa.

> **Alcance:** este es un proyecto académico de diseño y planificación. No representa una instalación física real ni la configuración de equipos de producción.

## Aspectos técnicos del diseño

- Arquitectura física y lógica con segmentación mediante VLANs y planificación de direccionamiento IP.
- Seguridad perimetral propuesta con pfSense, firewall, IDS/IPS, VPN y zona desmilitarizada (DMZ).
- Servicios institucionales previstos: Active Directory, DNS, DHCP y almacenamiento compartido.
- Plataforma de virtualización propuesta con Proxmox VE y estrategias de respaldo.
- Distribución física y cableado estructurado para un edificio institucional de tres plantas.
